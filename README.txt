ARIONDEZ — демонстрационный адаптивный сайт
==========================================

КАК ОТКРЫТЬ
1. Распакуйте архив ariondez-demo.zip.
2. Откройте файл index.html в браузере.
3. Для публикации на GitHub Pages загрузите содержимое папки ariondez-demo в корень репозитория и включите Settings → Pages → Deploy from a branch → main /root.

ЧТО РАБОТАЕТ
- Адаптивная мобильная и настольная версии.
- Навигация, мобильное меню, ссылки на телефон, Instagram и WhatsApp.
- Выбор услуги и типа помещения по нажатию на карточки.
- Форма генерирует готовое сообщение и открывает WhatsApp. Сервер, хранение персональных данных и API не требуются.
- Раздел FAQ и плавная анимация.
- Изображения (SVG) встроены в архив; Google Fonts для удобства подгружается онлайн, но сайт работает и без него.

ВАЖНО ПЕРЕД ПУБЛИКАЦИЕЙ
- Это не официальный сайт компании, а концепция для презентации собственнику.
- Телефон +7 705 789 33 77 и Instagram @ariondez.kz взяты из предоставленного пользователем изображения объявления.
- Условия лицензирования, гарантии, цена и география обслуживания требуют подтверждения владельцем.
- Для демонстрационной версии добавлен запрет индексации noindex,nofollow и пометка в подвале. После одобрения владельцем согласуйте реквизиты, юридическую информацию и снимите этот запрет.
